Q&A 03

高浓缩三元嵌段硅油

分类：常见问题

高浓缩三元嵌段硅油系列

SILICONE OIL SERIES
适用各种纤维织物提高柔滑挺弹度的后整理，特别是涤纶以及涤粘、涤棉等混纺织物。

抗起毛起球整理剂 WF-6505

适用于各种织物的抗起毛起球整理，具有良好的成膜性能。

  1. 赋予织物抗起毛起球性能，减少织物起毛倾向。
  2. 提高织物的抗磨性。
  3. 对织物手感影响小。

高浓亲水硅油 WF-6508

适用于棉、麻、涤等及其混纺织物。

  1. 能赋予纤维织物柔软、丰满和较好的透气、吸水及抗静电性能，尤其能使合成纤维克服起毛、起球的缺点。
  2. 属非离子、亲水性、官能型环氧改性硅油，有效含量高，不存在破乳漂油问题。
  3. 很容易稀释化料，可以与冷水以任意比例化料，通常 1:5-8 化开使用，操作简便。
  4. 较好的配伍性，可以与其它功能助剂复配使用。
  5. 再染性强，无需去除硅油而直接复染。
  6. 低黄变性。
  7. 可与氟系防污整理剂同浴使用，不会影响处理后织物的防污效果。

平滑嵌段整理剂 WF-8101N

适合于大部分纤维织物的手感整理，极大改善纤维滑度和蓬松度，尤其适合于合成纤维和蛋白质纤维。

  1. 新型自乳化织物柔软剂，赋予织物滑度和蓬松度，整理液具有良好的剪切稳定性及 pH 稳定性。
  2. 复配到氨基硅油乳液中可改善乳液稳定性。
  3. 配伍性好，可与防皱树脂及其催化剂、增白剂、非离子或阳离子助剂、酶类等同浴使用。
  4. 在较低浓度下仍有出色效果，提供合成纤维及混纺织物天然柔软度。
  5. 低黄变，适用于白色或浅色织物。

低温成膜整理剂 WF-8102N

适用于棉、涤等化纤面料及纱线的柔软整理，在超柔、仿超柔、涤纶毯上有较好的手感。

  1. 三元直链结构，不同于普通氨基硅油，不粘辊、不漂油、不残留油垢。
  2. 亲水性能好，能渗透到纤维内部，对厚重织物有较好的渗透柔软作用。
  3. 稳定性好，耐剪切、耐酸碱，可在 pH 3-10 条件下使用。
  4. 低温成膜，80-100℃ 烘干即有较好的手感。

蓬松嵌段整理剂 WF-8104N

适用于棉、涤等毛绒织物的手感整理，特别适用于涤纶、锦纶针织及毛绒织物。

  1. 稳定性好，耐剪切、耐酸碱，可在 pH 3-10 条件下使用。
  2. 三元直链结构，不粘辊、不漂油。
  3. 用量少时手感蓬松柔软，用量高时滑度表现明显且无油腻感。
  4. 能渗透到纤维内部，对厚中织物有较好的渗透柔软作用。
  5. 赋予毛绒织物干爽、不粘手、不油腻的蓬松带滑手感。

亮光增深整理剂 WF-8105N

适用于涤纶、棉及其混纺织物的增深亮光、弹性平滑整理。与柔滑剂配合使用，在毛绒类织物手感整理上效果显著。

  1. 特殊硅油乳液，平滑有弹性，对织物有明显的增深亮光效果。
  2. 与阳离子助剂配伍使用不会有化学反应。
  3. 手感弹性好，不粘手、不粘辊。
  4. 棉织物上有一定亲水效果。

人棉专用整理剂 WF-8109N/1

适用于各种棉、人棉及其混纺针织布的柔软整理，也适用于棉、麻、T/R、棉/锦等袋织布的柔软蓬松整理。

  1. 优异的化学稳定性，可在高剪切及较宽 pH 范围内保持乳液稳定。
  2. 低黄变，尤其适用于白色或浅色织物。
  3. 亲水性好。
  4. 赋予织物柔软、丰满、丝质般手感和突出的弹性效果。
  5. 浸渍工艺下可在常温溢流缸中加工，无硅油斑。
  6. 浸轧工艺不粘辊、无硅斑，易回修。
  7. 配伍性优良，可与少量涂料、固色剂、液体棉用增白剂及易去污整理剂同浴使用。

涤用松软硅油 WF-8106N

适用于棉、涤、涤棉混纺等化纤面料及纱线的柔软整理，尤其在中厚布类上有较好的松软手感。

  1. 三元直链结构，不粘辊、不漂油、不残留油垢。
  2. 能渗透到纤维内部，尤其对厚织物有较好的亲水蓬松柔软作用。
  3. 稳定性好，耐剪切，耐酸碱。
  4. 低温成膜，80-100℃ 烘干即有较好的手感。

涤、棉用整理剂 WF-8191A

适用于涤、棉及混纺织物的柔软整理，在 T/R、T/C 不倒绒后整理工艺上效果良好。

  1. 对织物渗透性好，柔和力强。
  2. 赋予织物滑爽、挺弹带柔的风格。
  3. 化学稳定性好，可与各种阳离子柔软剂配伍使用。
  4. 黄变小。

弹滑整理剂 WF-8203A

适合于人棉织物、罗马布类（T/R、N/R）等布种后整理处理，赋予织物柔滑、挺弹风格。

  1. 新型自乳化织物柔软剂，赋予织物滑度和挺弹度，整理液剪切稳定性及 pH 稳定性好。
  2. 配伍性好，可与防皱树脂及其催化剂、增白剂、非离子或阳离子助剂、酶类等同浴使用。

高手感亲水整理剂 WF-8204A

适用于棉、人棉、涤及其混纺织物的滑软亲水整理。

  1. 赋予织物柔软、柔滑、丝质般的后整理效果。
  2. 低黄变，适用于白色或浅色织物。
  3. 特殊分子结构，不粘辊、无硅斑、不漂油。
  4. 可与其它非离子、阳离子助剂配伍使用。

软、滑整理剂 WF-8205N

适用于各种毛绒类织物柔软整理，尤其适用于法兰绒。

  1. 赋予织物整体丰满、带滑度的手感效果，弹性好，干爽不粘手。
  2. 配伍性优良，可与其它阳、非离子助剂同浴使用。
  3. 低泛黄性，可用于白色或浅色织物。

松、软整理剂 WF-8206N

适用于涤腈、涤睛毛及涤纶织物的蓬松、柔软、滑爽整理。

  1. 良好的化学稳定性和配伍性。
  2. 低黄变。
  3. 赋予织物蓬松、柔软的手感。
  4. 对涤腈毛织物渗透性好，亲和力强。

高浓平滑整理剂 WF-8301N

适用于各种纤维织物，提高柔滑挺弹度手感，也可用于绒毛类如珊瑚绒的整理。

  1. 按 1:3 到 1:10 开稀，化料后呈透明稍带蓝光有机硅微乳液。
  2. 水溶性、稳定性和混用性好，能与阳、非离子助剂配伍使用。
  3. 赋予织物持久耐洗的柔滑、挺弹风格，可与蓬松整理剂复配。

高浓蓬松整理剂 WF-8402N

适用于各种纤维织物，提高织物柔软蓬松的手感。

  1. 按 1:3 到 1:10 开稀，化料后呈透明稍带蓝光有机硅微乳液。
  2. 水溶性、稳定性和混用性好，能与阳、非离子助剂配伍使用。
  3. 赋予织物持久耐洗的蓬松风格。

亮光柔滑整理剂 WF-8403

适用于涤纶不倒绒、T/C 不倒绒、全棉毛巾布等绒类产品，具有良好的滑软手感及光泽亮度。

  1. 适合浸渍、浸轧加工，整理后织物油性好、柔滑手感佳。
  2. 化学稳定性好，可与各种阳离子柔软剂配伍。
  3. 可单独使用，也可与柔软剂搭配使用，效果更佳。

亲水冰感硅油 WF-8499

适用于纯棉、棉拉架织物、丝光棉的亲水冰感爽滑整理。

  1. 亲水效果好，热稳定性好，耐剪切，可缸中使用。
  2. 手感柔软、滑爽，冰凉丝质感明显。
  3. 极低黄变。
  4. 不含 APEO。

环保去油灵 WF-201F

适用于涤纶、腈纶及其混纺织物缸、长车前处理的去油污，也可用于其它织物的去油、退浆、煮练及净洗处理。用量少，效果显著。
